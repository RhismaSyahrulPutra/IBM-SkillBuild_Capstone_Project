<h1 align="center">Country Explorer REST API</h1>

<p align="center">
  Capstone Project: IBM SkillBuild Back-End Development
</p>

<p align="justify">Country Explorer is a capstone project from the IBM SkillBuild program with a focus on back-end integration using Node.js. The project extends a front-end application by introducing a custom Node.js server that connects to the REST Countries API, replacing static JSON data with dynamic server-driven content. It demonstrates core back-end concepts such as server creation, routing, and API handling, while maintaining a responsive front-end built with HTML, CSS, and JavaScript.</p>

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (HTTP Module)
- [REST API](https://restcountries.com/) (REST Countries API)
- Core Concepts: MVC Pattern, RESTful Routing, Asynchronous Programming

## ✨ Features

- 🌍 Displays a large dataset of countries fetched from the REST Countries API
- 🔍 Search countries by name or native name, region, and population
- 🏳️ Displays country information including flag, name, population, capital, and region
- 📊 Shows detailed country information such as native name, flag, population, region, sub-region, capital, currencies, and languages
- 🔗 Integrated with REST Countries API using a Node.js backend for dynamic data fetching

## ⚙️ Installation

Clone this repository to your local machine:

```bash
git https://github.com/RhismaSyahrulPutra/IBM-SkillBuild_Capstone_Project.git
```

This command is used to copy the project repository from GitHub to your local computer.

Navigate to the project folder:

```bash
cd Country_Explorer_REST_API
```

This command moves you into the project directory that has been cloned.

Navigate to the backend folder:

```bash
cd backend
```

Open the project in Visual Studio Code:

```bash
code .
```

This command is used to enter the backend directory where the Node.js server is located.

Install dependencies:

```bash
npm install
```

This command installs all required dependencies listed in the `package.json` file.

Run the application:

```bash
npm start
```

This command starts the Node.js server using nodemon, allowing the server to automatically restart when changes are made.
