<h1 align="center">Country Explorer</h1>

<p align="center">
  Capstone Project: IBM SkillBuild Front-End Web Development
</p>

<p align="justify">Country Explorer is a capstone project from the IBM SkillBuild Front-End Web Development program that focuses on building a front-end web application using HTML, CSS, and JavaScript, where users can explore country information through an interactive interface while applying core web development skills such as UI design, DOM manipulation, event handling, input validation, and handling application logic based on functional requirements and wireframe specifications.</p>

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ✨ Features

- 🌍 Displays data for 24 countries
- 🔍 Search countries by name or native name, region, and population
- 🏳️ Displays country information including flag, name, population, capital, and region
- 📊 Shows detailed country information such as native name, flag, population, region, sub-region, capital, currencies, and languages

## ⚙️ Installation

Clone this repository to your local machine:

```bash
git https://github.com/RhismaSyahrulPutra/Country-Explorer.git
```

This command is used to copy the project repository from GitHub to your local computer.

Navigate to the project folder:

```bash
cd Country-Explorer
```

This command moves you into the project directory that has been cloned.

Open the project in Visual Studio Code:

```bash
code .
```

This command opens the project in VS Code so you can start viewing and editing the code.
